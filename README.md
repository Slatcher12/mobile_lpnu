# 🪄 Магічний Лічильник - Flutter Lab 1

Інтерактивний Flutter додаток з магічними заклинаннями для керування лічильником.

## ✨ Функціонал

### Основні можливості:
- **Інкремент** - натисніть кнопку `+` для збільшення лічильника на 1
- **Додавання чисел** - введіть будь-яке число для додавання або віднімання від лічильника
- **Магічні заклинання** з різними ефектами:

#### 🎭 Доступні заклинання:

1. **Avada Kedavra** 💀
   - Скидає лічильник до 0
   - Показує анімацію знищення

2. **Wingardium Leviosa** 🪄
   - Подвоює поточне значення лічильника
   - Ефект "піднімання" з анімацією

3. **Lumos** 💡
   - Змінює колірну тему на світлу (янтарну)
   - Підсвічує інтерфейс

4. **Nox** 🌑
   - Повертає колірну тему до початкової (фіолетової)
   - Гасить світло

### Інтерактивні елементи:
- Поле вводу з валідацією
- Кнопка "Застосувати" для виконання команди
- Кнопка "Очистити" для очищення поля вводу
- Кольорові повідомлення про результат дії
- Анімація масштабування лічильника при магічних діях

## 🚀 Як запустити

1. Переконайтеся, що Flutter SDK встановлений:
```bash
flutter doctor
```

2. Отримайте залежності:
```bash
flutter pub get
```

3. Запустіть додаток:
```bash
flutter run
```

## 🧪 Тестування

Запустити тести:
```bash
flutter test
```

Перевірити код аналізатором:
```bash
flutter analyze
```

Відформатувати код:
```bash
dart format .
```
